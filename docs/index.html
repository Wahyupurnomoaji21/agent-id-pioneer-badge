How it works

1. Connect your wallet (Binance Wallet or MetaMask) on BNB Chain (chain ID 56).
2. The page reads your Agent ID balance on-chain — no sign-in, no QR code, no session stored anywhere.
3. If you hold an Agent ID, press “Mint your free Badge” and confirm the transaction in your wallet.
4. One badge per wallet. It is soulbound (non-transferable), just like Agent ID itself.
